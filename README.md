"Journal Entry".

A simple Java project demonstrating the basic concept of double-entry bookkeeping.

Project Description:

This project represents a basic accounting transaction using Java.

In double-entry bookkeeping, every transaction has at least two entries:

- Debit
- Credit

The total debit amount must equal the total credit amount.

Example Transaction:

The business receives €1,000 from the owner.

Account| Debit| Credit
Cash| €1,000| €0
Owner's Capital| €0| €1,000

Total Debit: €1,000
Total Credit: €1,000

How to Run:

1. Open the project in VS Code.
2. Open "JournalEntry.java".
3. Compile and run the program.
4. The journal entries will be displayed in the terminal.
